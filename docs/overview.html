五、核心 API 速查
方法路径作用调用方
POST/scan扫码入库，分配货架编号Kiosk 前端
POST/scan/{id}/assign输入尾号，匹配员工，推送通知Kiosk 前端
GET/pickup/confirm/{id}取件确认页面（钉钉链接打开）钉钉 → 浏览器
POST/pickup/{id}确认取件（API 调用）工作台 H5
GET/my-packages员工待取包裹列表工作台 H5
GET/unclaimed所有待认领包裹管理员
POST/employees/sync从钉钉同步员工手机尾号管理员 / 定时
GET/employees/by-tail/{tail}手机尾号查员工（工作台登录）工作台 H5
GET/health健康检查 + 定时任务状态运维

七、NAS 部署步骤
① Mac 上
构建 Kiosk：cd kiosk && npm run build，复制到 backend/kiosk_dist/
② Mac 上
打包（排除 .venv / .env）：tar -czf ~/Documents/parcel-kiosk-deploy.tar.gz --exclude='.venv' --exclude='.env' backend docker-compose.yml
③ Mac 上
上传：scp ~/Documents/parcel-kiosk-deploy.tar.gz admin@192.168.3.27:/volume1/
④ NAS SSH
mkdir -p /volume1/docker/parcel-kiosk/data
tar -xzf /volume1/parcel-kiosk-deploy.tar.gz -C /volume1/docker/parcel-kiosk/
⑤ NAS SSH
手动创建 backend/.env（含钉钉密钥，不通过 scp 传输保护安全）
⑥ NAS SSH
cd /volume1/docker/parcel-kiosk && docker-compose up -d
⑦ 验证
curl http://192.168.3.27:8000/health 返回 {"status":"ok"} 即成功
