# 公司内部快递自助系统 设计文档

**日期**：2026-06-06  
**状态**：待实施

---

## 背景与问题

公司约 500 名员工，快递间每天收到 100 件以内的包裹。货架按快递公司分层摆放，员工知道包裹到了，但到货架前仍需花较长时间翻找。目标是实现类似菜鸟驿站的「编号取件」体验，大幅降低找包裹的时间。

---

## 核心设计目标

- 快递员自助完成登记，公司**零人工介入**
- 员工通过钉钉收到通知，看到编号，直接去找对应标签
- 快递员**看不到任何公司员工信息**，杜绝通讯录泄露风险
- 匹配失败的包裹有兜底处理路径

---

## 系统架构

```
[快递员]                         [员工]
   ↓                               ↑
自助扫码机 ──→ 后端服务 ──→ 钉钉机器人推送
   ↓              ↓                ↑
热敏打印机     数据库          钉钉小程序
              (包裹记录)      (待认领查询 + 取件确认)
```

---

## 核心流程

### 正常流程（手机号匹配成功）

1. 快递员在机器上扫包裹条码（约 3 秒）
2. 后台从条码数据中提取完整手机号
3. 用手机号查询钉钉企业通讯录，找到对应员工
4. 分配唯一编号（格式：`MMDD-序号`，如 `0606-023`）
5. 热敏打印机打印标签，快递员贴上包裹放架子
6. 钉钉机器人推送消息给员工

**钉钉通知内容示例：**
```
📦 你有快递到了！
编号：0606-023
快递公司：顺丰
请到快递间货架找对应编号取件。
[✅ 已取件]
```

### 未匹配流程（员工用私人号码收件）

1. 扫码后系统无法匹配到员工
2. 打印「待认领」标签（如 `待认领-0606-024`）
3. 快递员放到货架末端专属「待认领」格
4. 员工在钉钉小程序中查看待认领包裹列表（显示快递公司、到件日期），自行认领

## 标签设计

```
┌─────────────────────────┐
│  顺丰  │   0606-023     │
│        │   （大字体）   │
│  到件：2026/06/06 14:32 │
└─────────────────────────┘
```

- 标签**不含任何员工姓名、部门、联系方式**
- 仅含：快递公司简称、编号、到件时间
- 标签尺寸建议：60mm × 40mm 热敏纸

---

## 快递员操作界面（极简设计）

- 屏幕只显示一个操作入口：「**请扫描包裹条码**」
- 扫描后显示：`✅ 成功，请取出标签贴到包裹上` 或 `❌ 扫描失败，请重试`
- **无搜索框，无员工列表**，彻底消除安全风险
- 支持中英文提示，方便不同快递员使用

---

## 员工钉钉小程序功能

| 功能 | 说明 |
|------|------|
| 我的包裹 | 查看待取/已取包裹列表 |
| 待认领包裹 | 浏览未匹配包裹，按快递公司/日期筛选，点击「这是我的」完成认领 |
| 取件确认 | 点击「已取件」标记包裹完成 |

## 取件闭环设计

### 主路径：钉钉通知内嵌按钮

员工收到推送时，消息底部直接附带操作按钮，取到包裹后点一下即完成闭环，无需额外设备或扫码：

```
📦 你有快递到了！
编号：0606-023
快递公司：顺丰
请到快递间货架找对应编号取件。

[✅ 已取件]
```

点击后系统将该包裹状态从 `pending` 更新为 `picked_up`，记录取件时间。

### 兜底机制（防止员工忘记确认）

| 机制 | 触发条件 | 动作 |
|------|---------|------|
| 超时提醒 | 到件后 48 小时未取件 | 钉钉再推一条提醒消息 |
| 自动归档 | 到件后 7 天仍未操作 | 状态自动标记为 `expired`，从活跃列表移除 |

### 备用路径：钉钉小程序手动确认

若员工错过了通知，可在钉钉小程序「我的包裹」列表中找到记录，手动点击「已取件」完成确认。

## 数据模型（核心表）

**packages（包裹表）**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT | 主键 |
| code | VARCHAR | 编号，如 `0606-023` |
| courier | VARCHAR | 快递公司 |
| employee_id | VARCHAR | 匹配到的钉钉用户 ID |
| phone_tail | VARCHAR(4) | 收件手机后4位（仅未匹配时保存，用于员工自认领） |
| status | ENUM | `pending` / `picked_up` / `unclaimed` |
| arrived_at | DATETIME | 到件时间 |
| picked_at | DATETIME | 取件时间 |

---

## 安全考量

- 后端**不存储明文手机号**，仅用于实时查询后丢弃
- 匹配失败时仅保留手机后4位（`phone_tail`），用于员工自认领，无法反查真实号码
- 快递员界面无任何员工数据暴露入口
- 钉钉通知仅发给匹配员工本人
- 待认领包裹展示：快递公司 + 到件时间 + 手机尾号，信息最小化
